Most of my work is on ports, shipping and climate. Open to data, applied AI and sustainability analytics roles in the Netherlands, across Europe and remotely.

## How I work

```text
real-world question → public data → cleaning, validation, harmonisation
→ analysis and models (statistics, ML, CV, NLP) → open dataset with DOI
→ tool people use (web app, library, MCP server for LLMs) → decision
```

Every project ships with documented methods, stated limitations, a licence and citation metadata.
